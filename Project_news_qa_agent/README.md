## 검색 성능 평가

질문을 그대로 검색하는 기본 방식과 검색 텍스트를 확장하는 방식의 효과를 비교하기 위해 다음 네 가지 조건을 평가했습니다.

| 조건          | 설명                         |
| ----------- | -------------------------- |
| Base        | 사용자의 질문 원문만 임베딩하여 검색       |
| HyDE only   | 질문으로부터 가상의 기사 문장을 생성한 뒤 검색 |
| MultiQ only | 질문을 여러 표현으로 재구성하여 검색       |
| Both        | HyDE와 Multi-Query를 함께 적용   |

### 평가 방법

평가에는 서로 다른 유형의 검색 난도를 포함할 수 있도록 다음 세 가지 주제를 사용했습니다.

* **당근**: 기업·플랫폼 관련 기사와 채소 관련 기사가 혼재하는 동음이의어 주제
* **서울여대**: 학교명과 관련 기관·인물·입시 정보를 검색하는 고유명사 주제
* **강남**: 지역명과 방송인 이름이 동일한 동음이의어 주제

총 26개의 골든 질문을 구성했으며, 검색된 상위 기사 중 정답을 확인할 수 있는 필수 키워드가 포함된 기사가 하나 이상 존재하면 검색 성공으로 판정했습니다.

이 평가는 생성된 답변의 정확도나 충실도를 측정하는 것이 아니라, 정답 근거가 포함된 기사를 검색했는지를 측정하는 **Retrieval Hit Rate** 평가입니다.

### 평가 결과

| 주제           |   문항 수 |      Base | HyDE only | MultiQ only |      Both |
| ------------ | -----: | --------: | --------: | ----------: | --------: |
| 당근           |     10 |     50.0% |     50.0% |       50.0% |     50.0% |
| 서울여대         |     10 |     70.0% |     70.0% |       70.0% |     70.0% |
| 강남           |      6 |     66.7% | **83.3%** |       66.7% | **83.3%** |
| **Micro 평균** | **26** | **61.5%** | **65.4%** |   **61.5%** | **65.4%** |

주제별 결과를 동일한 비중으로 계산한 Macro 평균은 다음과 같습니다.

| 조건          | Macro Hit Rate |
| ----------- | -------------: |
| Base        |          62.2% |
| HyDE only   |      **67.8%** |
| MultiQ only |          62.2% |
| Both        |      **67.8%** |

### 결과 분석

HyDE를 적용한 결과 전체 검색 성공률은 **61.5%에서 65.4%로 3.9%p 향상**되었습니다.

특히 방송인과 지역명이 동일한 `강남` 주제에서 Base 검색은 6개 질문 중 4개를 검색했지만, HyDE는 5개를 검색하여 Hit Rate가 **66.7%에서 83.3%로 향상**되었습니다. 이는 질문의 표현과 기사 본문의 표현이 직접 일치하지 않는 경우, HyDE가 생성한 가상 기사 문장이 의미적 검색을 보완했기 때문으로 해석할 수 있습니다.

반면 Multi-Query는 단독 적용 시 Base와 동일한 성능을 보였으며, HyDE와 함께 적용해도 HyDE 단독보다 추가적인 개선이 나타나지 않았습니다.

```text
Base        : 16/26 (61.5%)
HyDE only   : 17/26 (65.4%)
MultiQ only : 16/26 (61.5%)
Both        : 17/26 (65.4%)
```

### 최종 검색 방식

최종 시스템에는 **HyDE만 적용**했습니다.

HyDE와 Multi-Query를 함께 사용한 조건이 HyDE 단독과 동일한 성능을 보였기 때문에, 추가적인 LLM 호출 비용과 검색 파이프라인의 복잡도를 고려하면 HyDE만 사용하는 것이 더 효율적이라고 판단했습니다.

평가 결과를 통해 HyDE가 모든 질문의 검색 결과를 일관되게 개선하는 것은 아니지만, 질문과 기사 사이의 표현 차이가 큰 일부 의미 기반 질문에서 검색 성능을 보완할 수 있음을 확인했습니다.

> 뉴스 검색 결과는 실행 시점과 수집된 기사에 따라 달라질 수 있습니다. 따라서 본 수치는 2026년 7월 30일 수집된 최근 50일 이내의 기사를 기준으로 한 실험 결과입니다.
