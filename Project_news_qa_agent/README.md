### 하이브리드 관련성 필터

뉴스 검색에서 발생하는 노이즈를 두 가지 방식으로 처리합니다.

첫째, LLM이 사용자의 검색 의도와 다른 **동음이의어 제외 키워드**를 생성합니다.

```text
강남 / 방송인
→ 강남구, 강남역, 강남 학원

당근 / 회사
→ 당근 재배, 당근 농가, 당근 효능
```

제외 키워드는 같은 업종의 경쟁사나 다른 기관이 아니라, 의미가 명확히 다른 표현만 생성합니다.

둘째, 기사에 `topic` 전체 문자열이 직접 등장하면 우선 통과시키는 **직접 언급 보호 규칙**을 적용합니다.

예를 들어 `서울여대`를 검색했을 때 기사에 `서울`과 `여대`가 따로 등장하는 것은 직접 언급으로 인정하지 않고, `서울여대`라는 전체 문자열이 있어야 보호합니다.

전체 필터링 과정은 다음과 같습니다.

1. LLM으로 동음이의어 제외 키워드 생성
2. topic 직접 언급 기사 우선 통과
3. 제외 키워드와 기사 간 임베딩 유사도 계산
4. 명확한 기사는 즉시 통과 또는 제외
5. 경계 구간 기사만 LLM이 최종 판정

제외 키워드는 topic 문자열을 제거한 맥락어만 임베딩합니다.

```text
당근 재배 → 재배
당근 농가 → 농가
```

이를 통해 동일한 단어가 포함됐다는 이유만으로 관련 기사가 잘못 제외되는 문제를 줄였습니다.

---

## 동작 흐름

1. 관심 분야, 검증 키워드, 수집 기간을 입력받습니다.
2. LLM이 뉴스 검색 키워드를 생성합니다.
3. 네이버 뉴스 검색 API로 기사를 수집합니다.
4. 기사 본문을 크롤링하고 임베딩합니다.
5. 동음이의어 제외 키워드를 생성합니다.
6. 직접 언급 보호, 임베딩, LLM 판정을 통해 관련 기사를 필터링합니다.
7. 의미적으로 중복된 기사를 제거합니다.
8. FAISS 인메모리 벡터스토어를 구축합니다.
9. HyDE 기반으로 관련 기사를 검색합니다.
10. 검색된 기사만 근거로 답변과 출처를 생성합니다.

```text
app/
  schemas.py                  # 데이터 모델
  query_understanding.py      # 뉴스 검색 키워드 생성
  news_search.py              # 네이버 뉴스 검색 API
  crawler.py                  # 기사 본문 크롤링
  embeddings.py               # 임베딩 클라이언트

```

## 관련성 필터 평가

`build_labeled_set.py`로 수집한 기사에 직접 관련 여부를 라벨링하고, `eval_filter.py`로 필터 성능을 비교했습니다.

평가 데이터는 서울여대, 강남, 당근 관련 기사 총 250건입니다.

```bash
python eval_filter.py
```

평가 방식은 다음과 같습니다.

* **V0:** 관련성 필터 없음
* **V1:** 동음이의어 제외 키워드 기반 필터
* **V2:** V1 + topic 직접 언급 보호

| 버전 | TP |  FP | FN |  TN | Precision | Recall |    F1 | Accuracy |
| -- | -: | --: | -: | --: | --------: | -----: | ----: | -------: |
| V0 | 78 | 172 |  0 |   0 |     0.312 |  1.000 | 0.476 |    0.312 |
| V1 | 55 |  61 | 23 | 111 |     0.474 |  0.705 | 0.567 |    0.664 |
| V2 | 78 |  97 |  0 |  75 |     0.446 |  1.000 | 0.617 |    0.612 |

동음이의어 필터를 적용한 V1은 무관 기사를 줄이면서 Precision과 Accuracy를 높였지만, 일부 관련 기사도 함께 제외되어 Recall이 감소했습니다.

직접 언급 보호를 추가한 V2에서는 False Negative가 `23건 → 0건`으로 감소했고, Recall이 다시 1.000으로 회복되었습니다.

최종적으로 V0 대비 V2 성능은 다음과 같이 개선되었습니다.

```text
Precision: 0.312 → 0.446
Recall:    1.000 → 1.000
F1:        0.476 → 0.617
Accuracy:  0.312 → 0.612
```

## 한계 및 개선 방향

* 직접 언급 보호는 `서울여대`와 같은 합성 고유명사에는 효과적이지만, 기업과 채소를 모두 의미하는 `당근`처럼 문자열 자체가 같은 동음이의어에는 한계가 있습니다.
* 관련성 필터의 임계값은 주제에 따라 조정이 필요할 수 있습니다.
* LLM이 생성한 제외 키워드에 따라 결과가 달라질 수 있습니다.
* 언론사별 HTML 구조에 따라 기사 본문 크롤링이 실패할 수 있습니다.
* 기사와 벡터스토어는 세션 종료 시 삭제됩니다.

향후에는 topic 유형에 따라 직접 언급 보호 적용 여부를 자동으로 결정하고, BM25와 벡터 검색을 결합한 하이브리드 검색 및 답변 품질 평가 기능을 추가할 예정입니다.
